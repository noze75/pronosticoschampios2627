Reglas de puntuación

  • 2 puntos → Se acierta el marcador exacto (resultado + goles de ambos equipos). Ejemplo: real 2-1 y se pronosticó 2-1.
  • 1 punto → Se acierta solo el resultado (quién gana o empate), pero no el marcador exacto. Ejemplo: real 2-1 y se pronosticó 3-0 o 1-0.
  • 0 puntos → Se falla el resultado completamente (pelmazo).

Desempate

  • Si hay empate a puntos, gana quien haya acertado más goles individuales (marcador de cada equipo por separado).
  • Ejemplo: partido real 2-1. Juan pronostica 3-0 → 0 goles acertados. Marrugo pronostica 0-1 → acierta el 1 del visitante → 1 gol acertado. Marrugo queda por delante en el desempate.
  • Si sigue el empate, se mira el número de marcadores exactos.

Cómo usar

  • Selecciona Soy con tu nombre (arriba). Sin elegir a nadie, todos los pronósticos están bloqueados; solo se activan los tuyos.
  • Los resultados reales se actualizan automáticamente (solo el admin puede editarlos).
  • Los datos se guardan solos en la nube. Arriba tienes Guardar por si quieres forzar el envío.
  • Cada 45 segundos se revisan cambios nuevos de los demás automáticamente.
